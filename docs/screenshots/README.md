# 运行截图采集说明

> 本目录存放 README 配图，全部由 `scripts/capture_screenshots.mjs` 自动采集（有头 Chromium，
> 1920×1080）。无头模式会走 SwiftShader 软渲染，Cesium 场景发黑且无光照，故不使用。

## 自动采集

服务跑起来后（后端 8001 / 前端 5174）：

```bash
cd yunnan-mine-twin
node scripts/capture_screenshots.mjs            # 全部 7 张
ONLY=03,07 node scripts/capture_screenshots.mjs # 只重拍指定编号
```

| 文件名 | 场景（URL hash） | 画面要点 |
| --- | --- | --- |
| `01-总体态势.png` | 无（默认视图） | 阶梯状矿坑地形、黄色运输道路、50 个监测点、三维矿卡、右侧工具箱 |
| `02-滑坡缓冲区.png` | `#shot=impact` | 红/橙/黄三层贴地缓冲区 + 右侧受威胁矿卡清单 + 一键撤离 |
| `03-溃坝推演.png` | `#shot=dam` | 尾矿库蓝色半透明淹没面 + 亮青边界 + 右侧实时水位/水深/面积 |
| `04-位移降雨耦合曲线.png` | `#shot=sensor` | 底部抽屉展开 72h 双轴曲线（位移速率 + 降雨柱） |
| `05-矿卡近景.png` | `#shot=truck` | 定格矿卡特写：车体贴地、居中，背景为盘山道路 |
| `06-等高线分析.png` | `#shot=contour` | 20m 等高距黄色等高线贴合采坑台阶 |
| `07-坡度着色.png` | `#shot=slope` | 40×30 网格坡度四级色块（绿/黄/橙/红）+ 右侧图例 |

> 场景等待时间见脚本顶部 `LOAD_WAIT` / `SCENE_WAIT`。地形瓦片是网络请求，
> 机器或网络慢时偶尔会拍到半加载画面，重跑单张即可。

## 手动交互截图（可选，更有说服力）

| 场景 | 路径 | 操作 |
| --- | --- | --- |
| 三维地形开挖 | 右侧工具箱 | 设开挖深度 45m → 点「采场三维地形开挖」→ 在矿坑内画多边形 |
| 土方量测算 | 右侧工具箱 | 点「采剥土方量测算」→ 圈选区域，读挖方/填方体积 |
| 主滑方向剖面 | 右侧工具箱 | 点「主滑方向地形剖面图」→ 沿北帮画一条线，底部出高程剖面 |
| 跟车巡检 | 右侧「矿卡巡检」 | 选一台矿卡，相机切到车头驾驶视角 |
| 地形夸张 | 左侧图层面板 | 拖动「地形夸张」滑块 1x→4x，对比地形起伏 |
| 等高线 / 坡度 | 左侧「地形分析」 | 下拉切换「等高线（20m）」或「坡度着色」 |
